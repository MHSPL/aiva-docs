# Report Templates

Templates provide pre-defined report structures with sections appropriate for specific use cases. Starting from a template saves time and ensures consistency across reports.

---

## Using a Template

1. Click **New Report** from the Reports section.
2. Select **From Template**.
3. Browse the available templates.
4. Select a template to preview its sections.
5. Click **Use Template** to create a new report with the pre-defined structure.

The template creates the report with all sections in place. You can then add content manually or use [AI Auto-Fill](ai-auto-fill.md) to populate each section.

---

## Available Template Types

### Clinical Variant Report

Designed for clinical laboratory reporting of variant findings.

**Sections included**:

- Patient Information
- Sample Information
- Methods
- Results
- Variant Summary Table
- Interpretation
- Recommendations
- Limitations
- References

### Research Summary Report

A concise report format for documenting research analysis findings.

**Sections included**:

- Study Overview
- Sample Description
- Analysis Methods
- Variant Statistics
- Key Findings
- Discussion
- References

### Pharmacogenomic Report

Focused on drug-gene interactions and prescribing implications.

**Sections included**:

- Patient Information
- Pharmacogene Panel Results
- Drug-Gene Interaction Summary
- Prescribing Recommendations
- Variant Details
- Methods
- Limitations
- References

### Comprehensive Genomic Report

A detailed report covering all aspects of genomic analysis.

**Sections included**:

- Executive Summary
- Patient and Sample Information
- Methods and Quality Metrics
- Variant Classification Summary
- Pathogenic and Likely Pathogenic Variants
- Variants of Uncertain Significance
- Pharmacogenomic Findings
- Secondary Findings
- Interpretation and Clinical Significance
- Recommendations
- Limitations and Disclaimers
- References and Data Sources

## Customizing Templates

After creating a report from a template, you can customize it freely:

- **Add sections**: Insert additional sections not included in the template.
- **Remove sections**: Delete sections that are not relevant to your analysis.
- **Rename sections**: Change section titles to match your organization's conventions.
- **Reorder sections**: Drag and drop to rearrange the report structure.

---

## Creating Custom Templates

To save a customized report structure as a reusable template:

1. Create a report with the sections and structure you want.
2. Open the report settings menu.
3. Select **Save as Template**.
4. Enter a template name and description.
5. The template is saved and available for future reports.

Custom templates appear alongside the built-in templates when creating new reports.

!!! tip "Organizational consistency"
    If your team uses a standard report format, create a custom template once and share it through your [project](../collaboration/projects.md). All team members can then create reports with the same structure.

---

## Template and AI Auto-Fill

Templates work seamlessly with [AI Auto-Fill](ai-auto-fill.md). When you use Auto-Fill on a template-based report:

- The AI recognizes the section type and generates content appropriate for that section.
- Section titles from the template guide the AI's output (e.g., "Pharmacogenomic Findings" produces drug-gene-focused content).
- You can Auto-Fill all sections sequentially or selectively fill only the sections where AI assistance is most valuable.
