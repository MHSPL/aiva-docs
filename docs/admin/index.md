## Accessing Administration

1. Log in with an account that has administrator privileges.
2. Navigate to **Administration** from the main navigation or settings menu.
3. The administration dashboard displays an overview of platform activity.

!!! note "Administrator access"
    Administration features are restricted to users with the administrator role. Contact your organization's administrator if you need elevated access.

---

## Administration Dashboard

The dashboard provides a summary of platform activity:

- **Active users** -- Number of users who have logged in recently.
- **Total samples** -- Count of uploaded samples across all users.
- **Storage usage** -- Total storage consumed by uploaded files and data.
- **Recent activity** -- Summary of recent uploads, analyses, and user actions.
- **System status** -- Health indicators for platform services.
